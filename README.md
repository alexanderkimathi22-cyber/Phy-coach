# Phy Coach

Phy Coach is a fitness and physical coaching concept designed to help people train smarter, recover better, and stay consistent.

## What this project includes

This repository currently includes a simple landing page and marketing mockup for the Phy Coach brand.

- Hero section with value proposition
- Feature highlights for coaching, tracking, and recovery
- Pricing cards for coaching plans
- Responsive layout for mobile and desktop

## Run locally

Open `index.html` in a browser, or serve the directory with a simple static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
